# checkie-translation

체키 성수 게임의 **게임 카드(컨셉·말투·진행 상황)**, **공용 용어집**, **번역·검수 프롬프트**를 팀이 함께 쓰는 사이트입니다.

- 첫 화면은 로그인 화면이에요. 로그인하지 않으면 내용을 볼 수 없습니다.
- 팀원은 **GitHub 계정 없이** 사이트에서 아이디로 회원가입합니다. 가입하면 ‘승인 대기 중’ 화면이 나옵니다.
- 관리자(기본 아이디 `yeun`)가 **보기 허용**과 **편집 허용**을 각각 켜고 끌 수 있고, 켜는 즉시 그 사람 화면이 자동으로 열립니다.
- 사이트는 Render에서 돌아가고, 데이터는 이 GitHub 저장소의 `data` 브랜치에 저장됩니다.
- 모든 수정은 `data` 브랜치에 커밋으로 남아서, 누가 언제 무엇을 바꿨는지 보고 되돌릴 수 있습니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `server.js` | 서버. 화면을 보여 주고, 회원가입·로그인·승인을 처리하고, GitHub에 저장 |
| `package.json` | Render가 서버를 실행할 때 쓰는 설정 |
| `public/index.html` | 사이트 화면 |
| `public/store.js` | 화면과 서버를 잇는 부분 |
| `public/vendor/xlsx.full.min.js` | 엑셀 파일 읽기 도구 (SheetJS, Apache-2.0) |
| `data/themes.json`, `data/terms.json` | 처음 데이터 (게임 카드 2개, 용어 13개) |

## 설정하기 (관리자 1회)

### 1. GitHub 저장소 만들기
1. GitHub → **New repository** → 이름 `checkie-translation` → **Private** 선택 → Create.
2. **Add file → Upload files**에서 이 폴더 **안의** 파일과 폴더(`server.js`, `package.json`, `README.md`, `public`, `data`)를 끌어다 놓고 Commit.

### 2. 서버용 GitHub 토큰 만들기
1. GitHub 프로필 → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. **Repository access**: *Only select repositories* → `checkie-translation`
3. **Permissions → Contents**: *Read and write*
4. 만료일은 길게(예: 1년) 잡고 Generate → `github_pat_…` 값을 복사해 둡니다.

이 토큰은 Render 서버에만 넣습니다. 팀원에게 나눠 주지 않습니다.

### 3. Render에 배포하기
1. render.com에 GitHub 계정으로 가입하고, `checkie-translation` 저장소 접근을 허용합니다.
2. **New → Web Service** → `checkie-translation` 저장소 선택
3. 설정
   - **Name**: `checkie-translation` → 주소가 `https://checkie-translation.onrender.com`이 됩니다. (이미 쓰이는 이름이면 뒤에 글자가 붙어요)
   - **Branch**: `main`
   - **Runtime**: Node
   - **Build Command**: 비워 두기 (필수라고 나오면 `npm install`)
   - **Start Command**: `npm start`
   - **Instance Type**: Free
4. **Environment Variables**에 아래를 추가하고 **Deploy**를 누릅니다.

| 이름 | 값 | 필수 |
| --- | --- | --- |
| `GITHUB_TOKEN` | 2번에서 만든 토큰 | 필수 |
| `GITHUB_REPO` | `계정이름/checkie-translation` (예: `xphobia/checkie-translation`) | 필수 |
| `ADMIN_ID` | 관리자 아이디. 비워 두면 `yeun` | 선택 |
| `ADMIN_PASSWORD` | 관리자 비밀번호. 비워 두면 `05197` | 선택 (넣는 것을 권장) |
| `ADMIN_NAME` | 관리자 이름 처음 값. 비워 두면 `김예은` (사이트의 ‘내 정보’에서도 바꿀 수 있음) | 선택 |

처음 데이터를 읽을 때 서버가 `data` 브랜치를 자동으로 만듭니다. 회원 목록은 `data/users.json`에 저장되며, 비밀번호는 암호화된 값(해시)으로만 남습니다.

## 회원 가입과 권한

1. 팀원이 사이트 주소를 열면 로그인 화면이 나옵니다. **회원가입** 탭에서 아이디·이름·비밀번호(4자 이상)를 넣습니다.
2. 가입하면 바로 **승인 대기 중** 화면으로 바뀝니다. 창을 열어 두면 됩니다.
3. 관리자는 아이디 `yeun`, 비밀번호 `05197`(또는 `ADMIN_PASSWORD`에 넣은 값)으로 로그인합니다. **회원 관리** 탭에 승인 대기 수가 표시됩니다.
4. 회원마다 두 개의 스위치가 있습니다.
   - **보기 허용**: 켜면 몇 초 안에 그 사람 화면이 자동으로 열립니다. 게임 카드·용어집을 보고 프롬프트를 복사할 수 있어요.
   - **편집 허용**: 켜면 게임 카드와 용어집을 고칠 수 있어요. 편집을 켜면 보기도 같이 켜집니다.
   - 보기 허용을 끄면 편집도 꺼지고, 그 사람은 다시 대기 화면으로 돌아갑니다.
5. 로그인은 30일 동안 유지됩니다.

| 관리자가 할 수 있는 일 | 방법 |
| --- | --- |
| 보기·편집 권한 주기/빼기 | **보기 허용**, **편집 허용** 스위치 |
| 비밀번호 잊은 팀원 | **비밀번호 초기화** → 화면에 나온 6자리 임시 비밀번호를 전달 → 팀원이 로그인 후 **비밀번호 변경** |
| 회원 지우기 | **삭제** (한 번 더 눌러야 실행) |
| 다른 사람도 승인할 수 있게 하기 | **관리자 지정** 켜기 (대표 관리자 yeun만 가능). 지정된 관리자는 일반 회원의 보기·편집 허용, 비밀번호 초기화, 삭제, 색 변경을 할 수 있어요. 관리자 지정·해제와 다른 관리자의 권한 변경은 대표 관리자만 할 수 있어요. |
| 회원 색 바꾸기 | 이름 앞 색 점 누르기 |

## 내 정보 (이름·색)

- 로그인 아이디와 화면에 보이는 이름은 따로예요. 예: 아이디 `yeun`, 이름 `김예은`.
- 오른쪽 위 이름이나 색 점을 누르면 이름과 색을 바꿀 수 있어요. 바꾼 이름은 진행 단계 버튼과 수정 기록에 표시돼요.

## 프롬프트 진행 순서

- **처음 한 번만**: A 분석 담당자 등록(ChatGPT 프로젝트 지침), B 번역 규칙 등록(언어별 번역 프로젝트 지침)
- **게임마다**: 1 원문 분석 → 2 번역 → 3 검수 → 4 테스트(원문 없이) → 5 재수정(걸린 문구만) → 확정
- 영어를 먼저 확정한 뒤 일본어·중국어를 진행해요.

## 번역 입력표 (PNG만 첨부하는 방식)

- 1 원문 분석에서 ChatGPT가 만들어 준 표 파일(xlsx)을 게임 카드 **번역 입력표**의 **파일 올리기**로 올려요. CSV나 표 텍스트 붙여 넣기도 돼요.
- 올린 표는 표 모양으로 미리 보이고, ‘확인 필요·판독 불확실’ 칸은 주황색으로 표시돼요. **엑셀(CSV)로 내려받기**로 받아서 고친 뒤 다시 올릴 수 있어요.
- 영어가 확정되면 최종 영어 표 파일을 **영어 확정본**에 올려요. ID와 번역문 열만 골라서 저장돼요.
- 프롬프트 탭의 P2-2·P2-3을 복사하면 이 표들이 자동으로 들어가요. 번역할 때는 **복사 → 붙여 넣기 → PNG 캡처 첨부**만 하면 돼요.
- ‘확인 필요’가 남아 있거나 표가 비어 있으면 게임 카드와 프롬프트 카드에 경고가 떠요.

## 용어집 화면

- **보기**: 입력 칸 없이 게임별로 묶어서 보여 줘요. 번역마다 확정·후보 표시와 ‘쓰지 않음’(금지 번역)이 함께 보여요.
- **추가·수정**: 표 형태로 용어를 넣고 고치는 화면이에요. 맨 아래 **+ 용어 추가**로 계속 추가할 수 있어요.
- 보기 화면의 **고치기**를 누르면 그 용어가 있는 추가·수정 화면으로 바로 이동해요. 보기 전용 회원에게는 보기 화면만 나와요.

## 회원 색

- 가입하면 다른 사람과 겹치지 않는 색이 자동으로 정해져요. 본인은 오른쪽 위 이름 앞 색 점을 눌러 바꿀 수 있어요.
- 게임 카드의 **진행 상황**에서 단계를 누르면, 그 버튼이 누른 사람의 색으로 칠해지고 이름이 같이 표시돼요.
- 앞 단계로 되돌리면 그 뒤 단계의 기록은 지워져요.

## 알아 둘 점

- **무료 Render는 15분 동안 아무도 안 쓰면 잠들어요.** 그다음 처음 열 때 30초~1분 정도 기다려야 합니다.
- 관리자 비밀번호를 바꾸려면 Render의 Environment에서 `ADMIN_PASSWORD`를 넣거나 바꾸고 저장하면 됩니다. 이때 모든 사람의 로그인이 한 번 풀립니다.
- 기본 비밀번호 `05197`은 코드에 적혀 있어요. 저장소는 꼭 **Private**로 두고, 가능하면 `ADMIN_PASSWORD`로 더 긴 비밀번호를 넣어 주세요.
- 알림 기능은 없어요. 가입한 팀원은 메신저로 알려 주고, 임시 비밀번호도 메신저로 전달해 주세요.
- 서로 다른 항목은 동시에 고쳐도 모두 저장됩니다. **같은 항목**을 동시에 고치면 나중에 저장한 쪽이 남습니다.
- 수정 기록 보기: GitHub 저장소 → 브랜치를 `data`로 바꾸기 → `data/terms.json` → **History**
- 잘못 지운 내용은 History에서 이전 버전을 열어 복사해 되살릴 수 있습니다.
- `main` 브랜치의 `data/*.json`은 처음 데이터일 뿐이에요. 실제 데이터는 `data` 브랜치에 있습니다.
